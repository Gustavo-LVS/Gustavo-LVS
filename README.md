# Gustavo Alves

Desenvolvedor full stack. Hoje trabalho na **TrackLand**, construindo os sistemas web internos que a equipe usa para planejar o transporte escolar: tratamento das planilhas da rede estadual, validação das entregas antes do envio e unificação de documentos em PDF.

**Stack do dia a dia:** Angular, TypeScript, Python (FastAPI), Docker, SQLite e Tailwind CSS.
